# Environment Artist

Modular, scalable environment and architectural site production. Storytelling through space and terrain.

## Grid & Architectural Standards

| Element | Standard Dimension | Notes |
|---------|--------------------|-------|
| 20ft Container Booth | 6.06m × 2.44m × 2.59m | Standard ISO 20ft module |
| 40ft Container Booth | 12.19m × 2.44m × 2.59m | Standard ISO 40ft module |
| Interior Ceiling | 2.4m–3.5m | Standard habitable clearance |
| Doors / Sliding Glass | 2.1m–2.4m height × 0.9m per leaf | Black aluminum / steel frame |
| Service Bar Counter | 1.00m–1.10m height × 0.60m depth | With 0.25–0.30m knee overhang for stools |
| Stairs / Steps | 0.15–0.18m rise × 0.28–0.32m run | Minimum 1.2m–1.8m public width |
| Stepping Pavers | 1.0m × 1.0m or 0.6m × 1.2m | Set in compacted gravel bed |

## Terrain & Landscape Layering

- **Base Terrain**: Anchor every site on a wider surrounding ground pad with road access so the site never floats in void
- **Retaining Walls**: Exposed river stone (*batu kali*) for structural grade changes; exposed red brick (*bata ekspos*) with dark concrete coping for perimeter privacy walls
- **Trees & Foliage**: Layer from tall canopy shade trees (*Ketapang Kencana* / *Terminalia mantaly*) to medium border foliage (*Calathea Lutea*, *Monstera*, *Heliconia*) to groundcover/gravel
